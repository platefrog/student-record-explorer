# 연구 재현과 TF-IDF 캐시 구조

## 연구 데이터와 공개 앱

공개 앱은 교사가 학생부 기록을 탐색하도록 학생별 상위 특징어와 근거 원문을 빠르게 보여 준다. 연구용 분석은 같은 전처리 조건을 사용하되, 사례 선정 지표를 상위어 절단 결과가 아니라 전체 양의 TF-IDF 벡터에서 계산한다. 학생 식별정보, 학생부 원문, 연구 캐시와 행렬은 저장소에 포함하지 않는다.

## TF-IDF 계산

1. 창체·교과세특·행발을 학년·반·번호·성명으로 병합한다.
2. Kiwi 기준 N 계열과 `SL`, `SH` 토큰을 추출한다.
3. 표현 통일 후 불용어를 제거한다.
4. 전체 학생 문서에서 다음 조건으로 한 번만 적합한다.

```python
TfidfVectorizer(
    token_pattern=r"(?u)\b\w+\b",
    norm="l2",
    use_idf=True,
    smooth_idf=True,
    sublinear_tf=False,
    min_df=1,
    max_df=1.0,
)
```

결과는 CSR 희소행렬로 유지한다. 전체 행렬을 밀집 배열로 바꾸지 않으며, 학생별 지표는 `matrix.getrow(i).data`의 모든 양의 값으로 계산한다. 동점은 TF-IDF 내림차순, 단어 오름차순으로 정렬한다.

## 전체 벡터와 상위 특징어

- 전체 벡터: 연구지표의 계산 기반이다.
- 캐시 상위어: 앱 탐색을 위해 학생별 최대 120개만 저장한다.
- 화면 표시: 기본 30개, 선택 10~100개다.
- 워드클라우드: TF-IDF 최대 120개 또는 빈도 최대 50개다.

캐시 저장 개수를 바꾸어도 전체 벡터 지표는 변하지 않는다.

## 캐시 스키마 v3

- `records`: 학생별 병합 원문
- `tfidf`: 학생별 상위 120개 TF-IDF 특징어
- `freq`: 학생별 상위 50개 빈도어
- `evidence`: 앱 분할 규칙에 따른 근거 원문 단위
- `tfidf_metrics`: 전체 양의 벡터 기반 지표
- `student_metrics`: 기록 구성, 영역 비중, 근거 범위, 학과 어휘 포착 지표
- `meta`: 앱·분석기·Python·라이브러리·사전 해시·저장 범위·특징공간 차원

구버전 캐시는 기존 특징어와 근거 원문을 계속 읽지만, 저장된 상위 30개로 120개나 전체 벡터 지표를 추정하지 않는다. 새 지표가 필요하면 원본을 다시 전처리한다.

## 기록 구성 지표

- `character_count`: `clean()` 적용 후 영역별 원문 문자 수의 합
- `token_count_before_stopwords`: 형태소 분석과 표현 통일 후, 불용어 제거 전 토큰 수
- `token_count`: 불용어 제거 후 분석 토큰 수
- `unique_token_count`: 중복 제거 토큰 수
- `evidence_unit_count`: 분할 후 분석 토큰이 남아 근거 인덱스에 저장된 원문 단위 수
- 영역 비중: 분모가 0이면 0

근거 원문 단위는 자연언어학적 문장 수가 아니다. 기록량과 토큰 수는 텍스트 양을 나타내며 학생의 역량·성실성·기록 품질을 뜻하지 않는다.

최소 단어 길이는 모든 분석기와 품사에 동일하게 적용하며 기본값은 2이다. 사용자가 선택한 길이보다 짧은 단어는 분석에서 제외하고, 실제 최소 길이는 캐시 분석정보에 저장한다.

## 전체 TF-IDF 지표

`positive_tfidf_feature_count`, `tfidf_max_full`, 상위 3·5·10 합과 전체 합, 상위 3·5·10 비중, 비영값 평균·표준편차와 정규화 엔트로피를 저장한다. 분모가 0인 행은 0으로 처리하고 검증 보고서에 건수를 남긴다.

## 근거 범위 지표

최고 특징어의 고유 근거 단위 수와 영역 수, 상위 3·5개 특징어의 합집합 근거 단위 수, 상위 30·60·120개 중 둘 이상의 영역에서 확인되는 특징어 수를 저장한다. 같은 근거 단위에서 같은 특징어가 반복되어도 한 단위로 센다. 실제 토큰 반복은 별도 `top_feature_occurrence_count`에 저장한다.

## 학과 말뭉치 어휘 포착률

기본 연구 관점은 `통합`이다. 학생 토큰 중 학과 TF-IDF 벡터라이저 어휘에 포함된 중복 토큰 비율과 고유 토큰 비율을 별도로 저장한다. 이 값은 현재 학과 말뭉치가 학생부 어휘를 포함하는 범위를 나타낼 뿐 학생 기록의 부족함을 의미하지 않는다. 계산 함수는 관점 인자를 받아 학업·교과·활동·적성·진로에도 확장할 수 있다.

통합 말뭉치는 학과명·세부학과명과 9개 상세정보 원자료 필드를 직접 한 번씩 결합한다. 학업과 교과 채널에 모두 포함되는 대학 주요 교과목도 통합 문서에서는 한 번만 들어간다. `research/audit_vocabulary_pipeline.py`는 필드별 공란·토큰·고유어휘와 통합 문서 전달 여부를 집계한다.

## 연구용 희소행렬 번들

`research/rebuild_full_tfidf.py`는 다음 로컬 파일을 생성한다.

- `student_tfidf_matrix.npz`: CSR 희소행렬
- `student_tfidf_vocabulary.json`: 열 순서 어휘
- `student_tfidf_row_mapping_PRIVATE.csv`: 행과 학생의 로컬 대응표
- `student_tfidf_full_metrics_anonymized.csv`: `case_id` 기반 전체 지표
- `student_tfidf_environment.json`: 실행 환경과 입력 해시

## 재전처리

```powershell
.\.venv\Scripts\python.exe research\rebuild_full_tfidf.py `
  --raw-dir "원본 39개 Excel 폴더" `
  --old-cache "기존 학생 캐시 DB"
```

기존 캐시는 덮어쓰지 않는다. 새 DB·Excel·NPZ·검증표는 `local_outputs/`에 저장되고 Git에서 제외된다.

## 후보군 안정성 검증

새 캐시로 사례 선정 스크립트를 다시 실행한 뒤 기존 후보와 `case_id` 기준으로 비교한다. 공통·신규·제외 후보, 후보 유형과 순위를 저장한다. 기존 주후보와 예비후보는 자동 교체하지 않는다.

## 개인정보

`local_outputs/`, `*_PRIVATE.*`, 연구 행렬과 캐시는 `.gitignore`로 제외한다. 익명 전달용 지표도 대응표와 이름 잔존 여부를 검증한 뒤 사용한다.
