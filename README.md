# 학생부 탐색기 v1.1.1

학생부의 창의적 체험활동, 교과 세부능력 및 특기사항, 행동특성 및 종합의견을 전처리하고 특징어와 근거 문장을 탐색하는 교사용 로컬 분석 도구입니다. 커리어넷 공개 학과정보와 학생부 기록의 텍스트 연계도도 확인할 수 있습니다.

- 최신 배포판: <https://github.com/platefrog/student-record-explorer/releases/latest>
- 현재 버전: **v1.1.1**

이 프로그램은 학생의 진로·역량·합격 가능성을 판정하거나 학생을 평가·서열화하는 시스템이 아닙니다. 결과는 원문 검토와 상담 질문을 돕는 참고자료로만 사용해야 합니다.

## 최근 성능 개선

현재 `main` 기준 성능 개선판은 전처리 캐시가 불러와진 학생 분석 화면의 첫 표시 중앙값이 **6.52초에서 1.81초로 줄어 약 72% 단축**되었습니다. 같은 기준으로 약 **3.6배 빠른 초기 표시**입니다.

- 학생을 고르는 동안에는 무거운 분석을 시작하지 않고, `선택한 학생 조회` 버튼을 누를 때 계산합니다.
- ZIP·Excel·DB 다운로드 파일은 버튼을 누를 때만 생성합니다.
- 말뭉치 DB 반복 쓰기, Kiwi 선로딩, 근거문장 전체 복사를 필요한 시점까지 미루고 워드클라우드는 캐시로 재사용합니다.

> 측정 조건: 동일 PC에서 동일한 1명 합성 학생 캐시를 사용해 개선 전 커밋(`00fb06c`)과 현재 코드를 각각 새 프로세스로 3회 실행한 `Streamlit AppTest` 중앙값입니다. 실제 속도는 PC 성능, 학생 수, 캐시 크기와 형태소 분석 설정에 따라 달라질 수 있습니다.

> 배포 범위: 위 성능 개선과 워드클라우드 표시 확장은 Windows 설치본·무설치본 v1.0.8부터 반영됩니다.

## TF-IDF 계산과 캐시 구조

- TF-IDF는 현재 불러온 **전체 학생 문서와 전체 어휘 공간**에서 하나의 희소행렬로 계산합니다.
- 전체 양의 TF-IDF 벡터에서 연구지표를 계산하며, 이 지표는 캐시에 저장하는 상위어 개수와 무관합니다.
- 앱 캐시에는 빠른 탐색을 위해 학생별 상위 120개 특징어만 저장합니다.
- TF-IDF 상세표는 기본 30개를 표시하며 사용자가 10~100개 범위에서 바꿀 수 있습니다. 표시 개수를 바꿔도 캐시를 다시 만들지 않습니다.
- 워드클라우드는 `TF-IDF 특징어`와 `단어 빈도`를 선택할 수 있습니다. 기본값은 TF-IDF이며, 각각 최대 120개와 50개를 사용합니다.
- 이전 캐시는 기존 특징어와 근거 원문을 계속 볼 수 있지만, 전체 벡터 지표와 확장 워드클라우드를 사용하려면 원본 학생부를 다시 전처리해야 합니다.

공개 앱의 상위 특징어는 기록 탐색용이며, 연구용 전체 벡터 지표와 용도가 다릅니다. 자세한 계산·재현 절차는 `docs/research-reproducibility.md`를 확인하세요.

## 기록 구성 정보

학생별 `student_metrics`에는 정제 후 문자 수, 불용어 제거 전후 토큰 수, 고유 토큰 수, 영역별 비중, 근거 원문 단위 수, 전체 TF-IDF 지표와 학과 말뭉치 어휘 포착률을 저장합니다.

- `근거 원문 단위`는 앱의 분할 규칙으로 만든 추적 단위이며 자연언어학적 문장 수가 아닙니다.
- 비율의 분모가 0이면 0으로 저장합니다.
- 기록량과 토큰 수는 기재된 텍스트의 양일 뿐 학생의 역량, 성실성 또는 기록 품질을 뜻하지 않습니다.
- 학과 말뭉치 어휘 포착률은 현재 학과 말뭉치의 어휘 공간이 학생부 토큰을 어느 정도 포함하는지 보여 주며, 학생 기록의 부족함을 뜻하지 않습니다.

## 실행

Windows에서 `run_dev.bat`를 실행합니다.

```powershell
.\run_dev.bat
```

터미널에 표시되는 `http://localhost:8501` 주소로 접속합니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

## 처음 사용하는 순서

1. `2. 학생부 전처리`에서 나이스 창체·교과세특·행발 `.xlsx.data` 파일을 올립니다. 일반 `.xlsx` 파일은 전처리에 사용할 수 없습니다.
2. 병합 미리보기에서 학년·반·번호·성명을 확인합니다.
3. Kiwi, MeCab 또는 간이 토큰화 중 현재 환경에서 사용할 수 있는 방식을 선택해 전처리를 실행합니다.
4. 전처리 결과를 ZIP, Excel, SQLite 중 하나로 저장합니다.
5. `3. 말뭉치 관리`에서 학과 말뭉치를 불러오거나 커리어넷 API로 갱신합니다.
6. 말뭉치를 검토하고 내장 DB로 저장합니다.
7. `1. 학생 분석`에서 학년·반·번호·학생을 선택한 뒤 `선택한 학생 조회`를 눌러 결과와 근거 원문을 확인합니다.

이후에는 원본 엑셀을 매번 전처리하지 않고 사이드바에서 전처리 결과를 불러와 사용할 수 있습니다.

## 나이스 원본 파일

- 창체: `나이스 > 학급담임 > 학교생활기록부 > 학생부 항목별 조회 > 창의적체험활동`
- 교과세특: `나이스 > 학급담임 > 학교생활기록부 > 학생부 항목별 조회 > 교과학습발달상황 > 세부능력및특기사항`
- 행발: `나이스 > 학급담임 > 학교생활기록부 > 학생부 항목별 조회 > 행동특성및종합의견`

학년·반은 엑셀 상단 또는 파일명에서 인식합니다. 권장 파일명은 `3학년 1반 창체.xlsx.data` 또는 `3-1반 창체.xlsx.data`와 같은 형식입니다.

## 주요 용어

- 전처리 캐시: 학생별 병합 원문, 빈도, 상위 TF-IDF, 근거 원문 단위, 전체 벡터 지표와 기록 구성 정보를 미리 계산해 저장한 결과입니다.
- Kiwi: 한국어 명사를 비교적 정교하게 추출하는 기본 형태소 분석기입니다. 최초 준비는 느리지만 같은 설정의 인덱스는 재사용합니다.
- MeCab: 빠른 형태소 분석기지만 한국어 패키지·사전과 Windows 실행 구성요소가 설치된 환경에서만 사용할 수 있습니다.
- 간이 토큰화: 글자 규칙과 간단한 어미 제거를 사용하는 빠른 방식입니다.
- 최소 단어 길이: 분석에 포함할 단어의 최소 길이이며 기본값은 2입니다. 분석기와 품사에 관계없이 더 짧은 단어는 제외됩니다.
- TF-IDF: 전체 학생에게 흔한 단어보다 특정 학생 기록에서 상대적으로 두드러지는 단어에 더 큰 값을 주는 통계값입니다.
- 근거 원문 단위: 프로그램의 분할 규칙으로 키워드 위치를 추적하는 단위입니다. 자연언어학적 문장 수와 동일하지 않을 수 있습니다.
- 코사인 유사도: 두 문서의 단어 가중치 방향이 얼마나 비슷한지를 나타냅니다. 확률이나 합격 가능성이 아닙니다.
- 말뭉치: 학생부와 비교하는 학과 설명 텍스트 묶음입니다.
- 보완 키워드: 목표 학과 말뭉치에는 상대적으로 강하지만 학생부 기록에는 약한 표현입니다. 학생의 결핍을 의미하지 않습니다.
- 적합·높은 연계: 현재 불러온 학생 전체와 학과 전체의 텍스트 유사도 분포에서 각각 상위 1%, 상위 5%에 해당하는 표시입니다. 진로 적성이나 합격 가능성이 아닙니다.

## 학과 말뭉치

커리어넷 학과 상세정보를 다음 관점으로 나누어 분석합니다.

- 통합: 학과명, 세부학과명과 9개 상세정보 원자료를 각각 한 번씩 결합한 문서
- 학업: 학과 개요, 특성, 대학 주요 교과목
- 교과: 관련 고교 교과와 대학 교과목
- 활동: 진로 탐색 활동
- 적성: 흥미와 적성 설명
- 진로: 졸업 후 진출 분야, 관련 직업과 자격

통합 문서는 채널(학업·교과 등)을 다시 합치지 않으므로 대학 주요 교과목이 중복되지 않습니다. 이 구성은 말뭉치 스키마 버전 3에 해당합니다. API 오류에는 요청 URL의 API 키가 저장되지 않으며, Windows에서는 `truststore`를 통해 시스템 인증서 저장소를 사용합니다.

커리어넷 갱신에는 승인된 API 키가 필요합니다. 키는 코드나 DB에 저장하지 않으며, 학생부 원문은 커리어넷으로 전송하지 않습니다. 수집 결과는 검토 후 `현재 말뭉치를 내장 DB로 저장`해야 다음 실행에서도 사용할 수 있습니다.

## 개인정보와 보관

- 로컬 실행에서는 학생부가 교사 PC에서 처리됩니다.
- 커리어넷 갱신 시에는 API 키와 공개 학과정보 요청만 외부로 전송됩니다.
- 업로드한 원본과 생성된 캐시에는 학생 식별정보와 학생부 원문이 포함될 수 있습니다.
- 임시 파일과 사용자가 저장한 결과 파일은 PC에 남을 수 있습니다.
- 외부 서버나 공용 PC에서 실행하면 로컬 처리 조건이 달라질 수 있습니다.

학교가 승인한 기기·계정·저장 위치를 사용하고, 접근 권한, 비식별화, 보관 기간, 결과 공유와 삭제 절차는 소속 기관 지침을 따라야 합니다.

## 결과 해석 시 주의

- 높은 유사도는 적성, 역량, 합격 가능성을 의미하지 않습니다.
- 낮은 유사도는 학생에게 경험이나 능력이 없다는 뜻이 아닙니다.
- 학생부는 학생의 모든 활동을 완전하게 담은 자료가 아닙니다.
- 단어 빈도는 활동의 중요성이나 학생의 우수성을 직접 나타내지 않습니다.
- 말뭉치, 불용어, 표현 통일 사전, 형태소 분석 방식이 바뀌면 결과도 바뀔 수 있습니다.
- 점수만 보지 말고 공통 키워드와 근거 원문을 함께 확인해야 합니다.

앱 안의 `5. 사용 안내` 탭에서 더 자세한 설명과 문제 해결 방법을 확인할 수 있습니다.
